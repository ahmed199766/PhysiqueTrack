# تطبيق تطور الوزن (PhysiqueTrack) — بناء ملف IPA بدون Mac

هذا المشروع جاهز بالكامل لبناء ملف **PhysiqueTrack.ipa** تلقائياً عبر **GitHub Actions** (مجاناً وبدون الحاجة لجهاز Mac).

## الميزات المدمجة
- **كاميرا التطابق الشفافة (Ghost Overlay):** تعرض آخر صورة التقطتها بنفس الزاوية بشفافية قابلة للتعديل + مؤقت ذاتي (3 / 5 / 10 ثواني) + شبكة محاذاة + تبديل الكاميرا الأمامية والخلفية.
- **تنظيم 3 زوايا:** أمامي، جانبي، خلفي لكل تسجيل مع الوزن ونسبة الدهون والملاحظات.
- **مقارنة قبل وبعد:** جنباً إلى جنب أو بشريط سحب تفاعلي (Slider) مع حساب فارق الوزن والدهون والأيام.
- **رسوم بيانية:** منحنى تطور الوزن ونسبة الدهون.
- **خصوصية كاملة:** الصور تُحفظ داخل التطبيق فقط ولا تختلط بالاستوديو + قفل بـ Face ID / رمز الجهاز + تصدير واستيراد نسخة احتياطية كاملة.

## خطوات استخراج ملف الـ IPA (دقيقتان فقط)
1. أنشئ مستودعاً جديداً (Repository) على **GitHub** (يمكنك جعله خاصاً **Private**).
2. فك الضغط عن هذا الملف وارفع جميع الملفات والمجلدات الموجودة داخله إلى المستودع (بما في ذلك المجلد المخفي `.github/workflows/build-ipa.yml`).
3. من صفحة المستودع في GitHub، اضغط على تبويب **Actions**.
4. سيعمل البناء تلقائياً (أو اضغط **Build iOS IPA** ← **Run workflow**).
5. انتظر دقيقتين حتى تظهر علامة الصح الخضراء، ثم ادخل على نتيجة البناء وحمّل الملف من قسم **Artifacts** باسم `PhysiqueTrack-IPA`.
6. فك الضغط عن الملف المحمّل لتجد `PhysiqueTrack.ipa` جاهزاً للتوقيع والتثبيت على الآيفون.
